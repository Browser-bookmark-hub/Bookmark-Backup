# 归档索引

本目录只保存历史开发计划、审计报告、迁移记录和阶段性验收材料。后续开发者或 AI 读取本仓库时，应以当前代码为唯一事实来源；这里的文档不能作为当前实现规范直接引用。

整理基准：2026-07-28 当前代码现状。

## 使用规则

- 需要理解当前行为时，先看 `Bookmark-Backup-main/` 的代码；本目录仅用于追溯设计源流。
- 本仓库已建立 CodeGraph：从仓库根目录运行 `codegraph status .` 可确认索引状态，运行 `codegraph sync .` 可同步后续改动。
- 文档标题中的状态优先于正文旧描述；正文里出现的“当前”“最终”“必须”“唯一权威”等字样可能已经过时。
- 恢复、撤销、安全快照、手动导出、`syncing` 根身份、favicon、网页快照工具都已经多次演进，必须以 `background.js`、`popup.js`、`dev_1/` 和 `history_html/` 当前代码为准。
- 本目录不保存新的实施计划；新计划应放到活跃文档区，完成或废弃后再归档。

## 当前代码事实摘要

- 恢复/撤销事务：`background.js` 中存在 `RESTORE_RECOVERY_TRANSACTION_KEY = 'restoreRecoveryTransaction'`、安全检查点、写锁/解锁、`beginRestoreRecoveryTransaction` / `completeRestoreRecoveryTransaction` 等链路；`popup.js` 有未完成事务提示和安全快照导出 UI。
- 恢复来源：主 UI 仍区分 WebDAV（云端1）、GitHub repo（云端2）和本地；恢复列表会识别 overwrite、versioned、manual_export、current changes 等不同类型。
- 手动导出：当前代码明确识别 `手动导出`、`manual export`、`manual_export`、`manual-export` 路径段，并把手动导出与云端恢复扫描做区分。
- 根身份：覆盖恢复的顶层根匹配已使用 `folderType` 与 `syncing`，在双根布局或根身份缺失时会阻断不精确覆盖。
- 本地标准 HTML：主 UI 在读取真实书签树后，若任一顶层根缺少 `folderType`，会把覆盖意图降级为导入合并；标题、语言和旧 ID 不作为放开覆盖的依据。
- HTML/JSON：仓库仍同时处理 HTML 快照、增强元数据、JSON/索引类辅助结构和历史记录能力判断；不要只按单一格式理解恢复。
- favicon：当前历史页和弹窗页各有一套 `FaviconCache`，共享 IndexedDB `BookmarkFaviconCache` / `favicons` / `failures`，后台 tab favicon 更新会转换为 data URL 后广播给前台缓存。
- 网页快照辅助工具：`dev_1/snapshot_helper_content.js`、`dev_1/dev1.js`、后台注入和 manifest command 共同组成当前链路。
- 高亮工具：`SnapshotHighlighter` 使用 `dev1_scoped_{tabId}_snapshot_highlighter_page_{hash}` 存储，刷新/自动恢复/休眠唤醒恢复都在当前实现里处理。
- 恢复后写出：恢复、补丁恢复、覆盖恢复和导入合并完成后的普通备份写出应按当前 `overwriteMode` 决定 `Overwrite` / `Versioned` 落点，来源记录只作为溯源信息。
- 备份历史自动清理：自动清理默认关闭；启用后按保留阈值和清理批量删除最旧历史记录，并清理对应的 `backup_data_*`、`changes_data_*` 或自定义变化数据 key。
- 当前变化实时刷新：当前变化视图可实时处理时，小变化优先增量修改 `cachedCurrentTree`，后台在已有有效缓存时尝试增量更新 `current-changes-cache:v3`，局部刷新当前变化区域；add/remove 前台批量达到 300、后台 bulk/import、缓存不可信或需要完整 diff 时回到完整当前树快照并重新计算 `treeChangeMap`。
- ID 与无稳定 ID 预览：`history.html` 里的预览基本走 ID 体系；`popup` 的 overwrite/patch/auto 快照恢复预览先通过后台补 ID、顶层根 remap 和 `normalizeTreeIds` 处理无稳定 ID 快照，再按 patch/overwrite 策略展示；changes-view merge 走独立提取链路。
- CodeGraph：`.codegraph/` 已初始化；数据库是本机索引文件，`.codegraph/.gitignore` 会忽略数据库和运行时文件。
